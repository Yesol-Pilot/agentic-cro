# Agentic CRO 최적화 스킬 매니페스트 (Optimized Skills Manifest)

원본 `antigravity-awesome-skills`에 포함된 900여 개의 대규모 스킬 세트 중, Agentic CRO 오픈소스 프레임워크의 성공적인 오케스트레이션을 위해 오직 **핵심적이고 관련된 24개의 스킬**만을 최적화하여 워크스페이스 내부에 이식했습니다. 불필요한 스킬로 인한 AI 에이전트의 컨텍스트 오염을 방지하고 작업 효율성을 극대화하기 위함입니다.

## 1. 프론트엔드 및 언어 기반 (Language & Frontend UI)

- `typescript-expert`, `typescript-advanced-types` : 메인 오케스트레이션 및 MCP 서버의 엄밀한 타입 검증 달성.
- `nextjs-best-practices`, `nextjs-app-router-patterns` : v0.dev 에이전트가 생성할 코드 베이스 기준.
- `react-best-practices`, `react-ui-patterns`, `tailwind-patterns` : 고품질 프론트엔드 컴포넌트 자동화 패턴 적용.

## 2. 모놀리식 타파 및 다중 에이전트 아키텍처 (Agents & Orcherstration)

- `multi-agent-patterns`, `autonomous-agents` : 에이전트 메시 아키텍처 구조화의 교과서.
- `mcp-builder` : 자사 서버와 LLM 간의 Model Context Protocol 통합 구축.
- `agent-tool-builder`, `llm-application-dev-langchain-agent` : LLM에 함수를 쥐여주는 외부 툴 구성 방법론.

## 3. 백엔드 및 클린 코드 (Backend & Software Quality)

- `nodejs-best-practices`, `nodejs-backend-patterns` : 빠르고 안정적인 오케스트레이터(Supervisor) 데몬 서버 아키텍처 수립.
- `clean-code`, `code-review-excellence` : 에이전트들이 생성한 PR의 품질 향상 및 자동 코드 리뷰 스탠다드.

## 4. 데이터 수집 및 QA (Data Analytics & QA)

- `playwright-skill`, `browser-automation`, `e2e-testing-patterns` : 경쟁사 벤치마킹을 위한 Shadow DOM 피어싱, 화면 캡쳐, 및 병합 후 프론트엔드 회귀 테스트용 도구.
- `data-scientist`, `posthog-automation` : 베이지안 테스트 평가를 위한 데이터 파이프라인 분석 스킬.

## 5. 깃허브 버전 관리 자동화 (GitHub & GitOps)

- `create-pr`, `github-workflow-automation`, `git-advanced-workflows` : A/B 테스트 검증 후 안전하게 `main` 브랜치에 병합(Merge)하는 일련의 자율형 배포 방식 확립.
